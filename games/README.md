# Games

One file per game: how it runs in Madeira on an iPhone 16 Pro (iOS 26, 6 GB jetsam limit with the
increased-memory entitlement), the settings that make it work, and its controller mapping.

- Config lines go in Madeira › the game › Advanced › This game's config.
- A controller mapping goes in Madeira › the game › Controller binds › Mapping as text › Paste
  (it switches the game's Controller to Keyboard and mouse).
- Launch options go in Steam's launch options for the game.
